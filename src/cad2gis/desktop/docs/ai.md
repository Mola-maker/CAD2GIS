# AI 配置与任务能力

## 配置排错
服务地址填写 API 基础地址，不是服务商网页地址。粘贴 chat/completions 地址时软件会去掉接口后缀。模型名称必须与当前服务支持的名称一致。

- 401：密钥无效或服务地址错误。
- 403：账号没有访问权限。
- 404：接口地址或模型名称不存在。
- 429：服务限流或额度不足。
- 超时：检查网络、代理、证书，必要时增加超时时间。
- 模型有响应但工具未通过：选择支持工具调用的模型。

高级选项可调整结构化输出方式、max_tokens / max_completion_tokens、超时和单次任务请求上限。不同 OpenAI 兼容服务可能支持不同参数。

## 智能体可以做什么
智能体复用完整 CAD2GIS MCP 工具目录，覆盖环境检查、图纸检查、工程建项、证据与语义审核、转换、OSM 匹配、SVG 候选、结果检查与交付。另有项目文本读取、新建 JSON 证据文件、只读数据库查询、上下文读取和计划更新工具。

对话支持多轮工具调用、过程展示、停止任务、历史恢复和用量记录。失败时显示实际失败状态，缺少证据时仍需补全原有审核要求。它不能替用户猜测图层业务含义或坐标系。

## 数据范围
仅访问启动时指定的项目目录，配置和凭证目录不开放给项目工具。新建 JSON 工具不覆盖已有文件。SQLite 查询不修改数据库。软件不提供任意系统命令执行。

模型运行需要可用的服务地址、模型和用户自己的密钥；安装包不包含共享密钥。对话中的相关项目文本和工具结果会发送到你选择的模型服务，请按项目要求选择服务。
