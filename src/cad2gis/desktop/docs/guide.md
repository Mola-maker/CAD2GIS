# 开始使用 molamaker / CAD2GIS

## 1. 连接 AI
打开底部「AI 配置」，选择 DeepSeek 或 OpenAI 兼容服务。填写 API 基础地址、服务商提供的模型名称和密钥。保存后点击「测试连接」；测试会实际调用模型和一个测试工具。

Windows 将密钥加密保存在当前用户的配置目录。重新打开软件无需再次填写。远程客户端使用服务器已有配置，需在服务器本机修改密钥。

## 2. 选择图纸并开始对话
点击「项目与文件」，上传 DWG 或选择已在项目目录里的图纸。默认项目目录为用户主目录下 CAD2GIS Projects。可在启动服务器时指定其他项目目录。

导入图纸后，在转换对话中发送“转换当前图纸”。智能体会使用已审核的项目配置；新项目则先完成 AI 建项，再执行正式转换。完成后点击聊天中的“打开转换结果”核对地图。必要坐标或分类证据不足时，会保留校验结果并说明缺少什么。

也可以要求“先检查图纸和坐标信息，给出转换计划”。右侧执行轨迹默认收起工具详情，点击一条记录即可展开并滚动查看。长输出在消息区内部滚动，输入框保持可用；点击停止可取消当前任务。对话和所选图纸保留在本机，历史记录支持分页。

也可以打开项目面板，直接执行环境检查、图纸检查、建立草稿、标准转换或 AI 建项与转换。每次转换选择新的结果目录。

## 先提取语义

从“工具与设置 → 语义提取”打开项目面板，选择 DWG，填写一个新的结果目录，点击“提取语义”。此步骤无需 AI 密钥：先读取原始实体、图层、文字与几何，再建立分类、标注和尺寸关系候选，最后验证源快照和候选的绑定。

三个阶段完成后可以下载两份清单及数据库，或直接只读查看源实体和候选。所有坐标保持 CAD 原坐标；候选等待审阅，不会自动提交分类、覆盖 baseline 或更改 GCP。“交给 AI 审阅”只把含产物位置的提示填入对话，检查后再发送。

取消后先等待“已停止”。已有阶段产物留在结果目录；点击“换一个新结果目录”后可以重试。失败时展开任务输出定位原因。文件存在不等于提取成功，只有来源验证通过才显示完成。

Windows、Linux 与 Android 所连接的服务器共享这一工作区。旧服务器不提供此能力时按钮不可用，需要升级服务器程序并重新连接。头像分别反馈按下、处理中、成功、失败和停止状态；系统启用减少动态效果时，状态文字与静态头像仍会保留。

## 3. 预览 OSM 匹配
底部「OSM 工作台」打开结果目录。默认使用 OSM 相对配准，最终输出使用匹配后的坐标并记录来源。相对配准不等同于测量控制精度。

人工 GCP 先用于预览。发现匹配不准时检查点对、坐标系和误差，再明确执行二次匹配。原始图纸与旧结果保留，便于对照。

## 4. 审阅 SVG 与数据库
「SVG 审阅台」显示当前结果绑定的 SVG 候选报告；未生成报告时会给出原因。「SQLite 可视化中心」浏览 SQLite / GeoPackage 表、字段和分页数据，也可执行只读 SELECT 查询。

## 操作提示
- 底部“图纸与 AI”“地图校正”“工具与设置”切换主要工作区，其他工具在设置面板中打开。
- 文件列表、会话列表、历史消息、任务记录和数据库结果均有分页。
- 关闭程序前等待任务完成或先停止任务。
- Windows / Linux 本机负责转换；Android 安装端连接服务器工作台。远程服务需要 HTTPS 和登录密码。

### 生成 QGZ 与查看 SVG

已有转换结果时，可以直接对 AI 说“生成 QGZ”。智能体会检查现有结果并创建新的 QGIS 交付目录和完整 ZIP；无需重复转换。下载完整 ZIP、解压后打开其中的 `.qgz`，保留配套 GeoPackage 和样式文件。

聊天区会显示“打开地图”“SVG / PNG 预览”“QGZ 与完整交付包”按钮，重启后仍可查看。SVG 候选报告展示已提取符号及未解析项；候选生成不代表全部图例匹配或已应用到 QGIS 样式，人工复核也不改变原有精度验收状态。
