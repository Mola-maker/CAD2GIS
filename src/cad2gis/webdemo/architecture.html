03 / OPTIONAL SVG

图例是一条
可选的复核支线。

默认保留原样式；开启候选入口，再逐项对照源图。

独立提取脚本与 symbols.sqlite3 保存 SVG、源句柄和对应关系。检测覆盖模型空间与图纸布局，结合图例候选和原始块实例生成对照 HTML。

  1. 选择 --svg-mode candidate
  2. 检查源实例与边缘图例候选
  3. 复核字体、动态块与遗漏项
  4. 将确认的来源绑定用于 QGIS 打包

候选匹配不是自动验收。九图 SVG 复跑已有记录，但完整图例一一对应仍未验收；缺失、嵌套句柄及渲染不完整项显式列出。

04 / DELIVERY

从本机到服务器，
用同一条转换流程。

CLI、MCP、批量契约共享转换内核，不绑定特定 AI 模型。

Linux 使用 LibreDWG，无需 AutoCAD。批量目录为每张图保留来源哈希、阶段日志、失败状态与 HTML 索引。服务器可以经 SSH 调用 CLI，或通过受控连接访问本地 MCP 服务。

便携 QGZ 将数据作为附件、SVG 作为内嵌矢量保存；完整交付包同时保留可编辑 GeoPackage、QML 和说明。QGIS 打包与实际渲染需要额外的 QGIS 环境，基础 Docker 镜像提供转换与 MCP 运行时。
