THE FIVE STEPS

先确认，再继续

  1. 01

    准备 Conda 环境

    先进入项目目录，再创建专用环境。这样 GDAL、PROJ 和 Python 依赖不会和你电脑里的其他项目混在一起。

    conda env create -f env/environment.yml
    conda activate cad2gis
    看到命令行左侧出现 (cad2gis)，这一关就通过了。
  2. 02

    安装插件与审查组件

    接下来安装 CAD2GIS 本体、MCP 接入、Web 审查界面和测试依赖。第一次构建需要一点时间，先让它完整跑完。

    pip install -e ".[mcp,review,test]"
    最后出现 Successfully installed cad2gis 即可，不必担心中间正常的依赖下载信息。
  3. 03

    在 Windows 选择 DWG Reader

    如果电脑已经安装 AutoCAD，就让 CAD2GIS 使用 Core Console 读取 DWG。这个设置只影响当前 PowerShell 窗口。

    $env:CAD2GIS_READER_BACKEND = "autocad"
    没有 AutoCAD 时也可以使用兼容的 LibreDWG reader；稍后的 doctor 会告诉你当前哪一种可用。
  4. 04

    限制插件可访问的目录

    把插件的文件权限收在项目根目录里。请把示例路径换成你实际存放 CAD 项目的位置。

    $env:CAD2GIS_PROJECT_ROOTS = "E:\branch_CAD2GIS"
    这是安全边界，不是可省略的“高级设置”。路径之外的文件默认不会被 MCP 工具读取。
  5. 05

    让 doctor 做最后检查

    安装完成后不要急着拿正式图纸测试。先让 doctor 检查 reader、GDAL、PROJ、MCP 和审查组件是否都能正常工作。

    cad2gis doctor --deep --strict --json
    所有必需检查通过后，再开始第一张 DWG；如果有失败项，输出里会直接指出缺什么。

YOUR FIRST RUN

装好以后，先做一次体检式转换

选一张有代表性、但不是唯一原件的 DWG。先检查，再为这张图建立 source-bound 项目配置；确认验证通过后，才生成新的 run 目录。

cad2gis inspect "<SOURCE.dwg>" --json
cad2gis bootstrap "<SOURCE.dwg>" --project "<PROJECT_DIR>" --json
cad2gis validate --project "<PROJECT_DIR>" --json
cad2gis convert "<SOURCE.dwg>" --project "<PROJECT_DIR>" --run-dir "<NEW_RUN_DIR>" --json
