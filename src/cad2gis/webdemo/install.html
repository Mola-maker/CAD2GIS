01 / SYSTEM

按操作系统安装 MCP 运行时

归档安装不拉取完整 Git 历史；--force 也会替换指向已删除 worktree 的旧 editable 安装。Windows 更新或修复前，先退出正在使用 CAD2GIS 的 MCP 客户端并停止 cad2gis review；否则运行中的 Python 进程会锁住工具目录并触发 os error 32。

01A

Windows PowerShell

winget install --id=astral-sh.uv -e
uv tool install --python 3.12 --force "cad2gis[agent] @ https://github.com/Mola-maker/CAD2GIS/archive/refs/heads/main.zip"
cad2gis runtime install
01B

macOS

brew install uv libredwg
uv tool install --python 3.12 --force "cad2gis[agent] @ https://github.com/Mola-maker/CAD2GIS/archive/refs/heads/main.zip"
01C

Linux

curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install --python 3.12 --force "cad2gis[agent] @ https://github.com/Mola-maker/CAD2GIS/archive/refs/heads/main.zip"
cad2gis runtime install
LIMIT

WSL 限制

WSL 使用上面的 Linux 命令运行无界面流程。WSL → Windows GUI 不作为受支持通道；需要控制 Windows AutoCAD 或 Windows QGIS 时，请在 Windows 原生 Codex / CLI 环境中安装。

GIS

完整转换环境

cad2gis[agent] 携带平台 GDAL/OGR wheel；再运行 cad2gis runtime install 安装 LibreDWG CLI。AutoCAD 与 Conda 都不是默认依赖。只有 cad2gis doctor --deep --strict --json 返回 conversion_ready: true 才表示可转换。

02 / CLIENT

按客户端注册插件

下面四个分块完整列出 Codex、Claude Code、Cursor 和 VS Code / Copilot 的接入命令。

CODEX

Codex

codex plugin marketplace add Mola-maker/CAD2GIS --ref main
codex plugin add cad2gis-agent@cad2gis
codex plugin list
CLAUDE

Claude Code

claude plugin marketplace add Mola-maker/CAD2GIS
claude plugin install cad2gis-agent@cad2gis-tools
claude plugin list
CURSOR

Cursor

将模板保存为 .cursor/mcp.json；它通过 ${workspaceFolder} 自动使用当前图纸工作区。

Windows PowerShell 
New-Item -ItemType Directory -Force .cursor | Out-Null
Invoke-WebRequest "https://raw.githubusercontent.com/Mola-maker/CAD2GIS/main/plugins/cad2gis-agent/clients/cursor.mcp.json" -OutFile ".cursor/mcp.json"
macOS / Linux
mkdir -p .cursor && curl -fsSL "https://raw.githubusercontent.com/Mola-maker/CAD2GIS/main/plugins/cad2gis-agent/clients/cursor.mcp.json" -o .cursor/mcp.json
COPILOT

VS Code / Copilot

将模板保存为 .vscode/mcp.json，再填写项目绝对路径。

Windows PowerShell 
New-Item -ItemType Directory -Force .vscode | Out-Null
Invoke-WebRequest "https://raw.githubusercontent.com/Mola-maker/CAD2GIS/main/plugins/cad2gis-agent/clients/vscode.mcp.json" -OutFile ".vscode/mcp.json"
macOS / Linux
mkdir -p .vscode && curl -fsSL "https://raw.githubusercontent.com/Mola-maker/CAD2GIS/main/plugins/cad2gis-agent/clients/vscode.mcp.json" -o .vscode/mcp.json

03 / LIFECYCLE

安装、验证、更新、修复、卸载

五组操作独立列出。修改插件或 MCP 配置后，请重启客户端并新建任务。

01

安装

先执行上面的操作系统分块，再执行对应的客户端分块。正式 marketplace 与 Pages 均只跟随 main。

查看安装分块
02

验证

cad2gis-agent-mcp --help
cad2gis doctor --deep --json
codex plugin list
claude plugin list

--help 验证 console script 可导入；doctor 可能报告控制面可用但 GIS runtime 为 limited。新任务中再调用 get_capabilities。

03

更新

Windows 上先停止 CAD2GIS MCP/WebUI 进程，再替换运行时，安装完成后重启客户端。

uv tool install --python 3.12 --force "cad2gis[agent] @ https://github.com/Mola-maker/CAD2GIS/archive/refs/heads/main.zip"
codex plugin marketplace upgrade cad2gis
codex plugin add cad2gis-agent@cad2gis
claude plugin marketplace update cad2gis-tools
claude plugin update cad2gis-agent@cad2gis-tools
04

修复 CONNECTION_CLOSED

若 CLI 报 ModuleNotFoundError: No module named 'cad2gis'，通常是 uv 的 editable 安装仍指向已删除 worktree。不要编辑插件缓存或 .pth；重新执行上面的强制归档安装，确认 cad2gis-agent-mcp --help 成功，再重启客户端并新建任务。

复制修复命令
05

卸载

codex plugin remove cad2gis-agent@cad2gis
claude plugin uninstall cad2gis-agent@cad2gis-tools
uv tool uninstall cad2gis

Cursor / VS Code 用户还需删除项目中的 MCP 配置文件。

YOUR FIRST RUN

装好以后，先做一次体检式转换

先检查图纸并建立 source-bound 项目配置，验证通过后再生成新的 run。没有实测 GCP 时，不把名义 CRS 或 OSM 粗锚定描述成绝对定位精度。

cad2gis inspect "<SOURCE.dwg>" --json
cad2gis bootstrap "<SOURCE.dwg>" --project "<PROJECT_DIR>" --json
cad2gis validate --project "<PROJECT_DIR>" --json
cad2gis convert "<SOURCE.dwg>" --project "<PROJECT_DIR>" --run-dir "<NEW_RUN_DIR>" --json
打开审查工作台回到产品介绍
