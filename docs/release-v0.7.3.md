# CAD2GIS 0.7.3 — 聊天转换与布局修复

长工具输出现在在聊天区和可展开的执行记录内滚动，输入框与发送按钮保持在窗口内。导入 DWG 后可发送“转换当前图纸”：已有审核配置进入正式转换，新项目完成必要的 AI 建项后转换，真实产物通过“打开转换结果”接入地图审阅。

## 修复

- 工作区上下文区分源文件、配置目录、结果目录和尚未生成的路径，并列出真实配置文件。新增分页目录工具，文本与数据库工具返回可执行的路径提示。
- 新项目不再要求配置目录预先存在。已有配置沿用正式入口的发现规则，支持项目根目录、config、.cad2gis 及 manifest 指定布局；部分或损坏配置保留错误，不静默重建。
- `debug_mcp.scope` 在工具 schema 中明确列出 `identity`、`runtime`、`artifacts`、`query`，防止使用无效值。
- 大型建项报告被截断时仍保留可解析的转换回执。完成的转换复用原回执，中断重试固定原工具与参数，保留不确定写入保护。
- 对话保留选中图纸和结果。快速切换对话时丢弃迟到响应，防止旧会话覆盖当前图纸。
- 延续 0.7.1 的可选 GCP、地图滚动及 SVG 审阅修复，以及 0.7.2 的覆盖安装占用保护。

## 本地验证

- 120 项 Python 回归通过；1 项符号链接测试因 Windows 账户不具备创建权限跳过。
- Edge 在 1440×900、1024×768、768×700、390×844 验证长工具输出、消息、输入框和发送按钮。
- 浏览器验证工具详情展开状态在轮询后保留、会话请求逆序返回，以及聊天结果打开实际地图。
- 真实 DWG → MCP 子进程 → 正式转换生成 GeoPackage、OSM 匹配与 SVG 报告，旧结果哈希不变，重复工具请求没有重复转换。
- 上述智能体集成测试使用确定性模型和本地 OSM 测试数据，没有调用远程模型服务。源图缺少必要坐标或分类证据时仍须满足正式转换的校验要求。
- 地图滚动、可选 GCP、SVG 图片及只读数据库审阅回归通过；Windows 启动器、单次登录和前端资源哈希校验通过。

本版本在本机构建，未运行 GitHub Actions。Windows 安装前从工作台关闭程序，避免旧 Python 进程占用运行环境。源码与依赖源码按已有授权随私有 Release 提供。
