# 全按钮人物 IP 与背景动效

本次复用已生成的 molamaker 六状态人物图，增强桌面、服务端 Web 界面及 Android 服务页面中的真实按钮。动态文件、对话、任务、数据库表和产物按钮通过同一个观察器接入；按钮名称、事件及服务接口保留。主要按钮和底栏常驻人物，其余按钮在悬停、焦点、按压或忙碌时显示。

按压反馈与任务结果分离。点击只产生短反馈；等待状态来自异步请求或任务运行；成功、失败、取消只跟随后端状态。第二次操作会清除旧任务结果，不能借用上一次成功。屏幕外、隐藏标签及后台页面暂停持续动画，系统“减少动态效果”时保留静态人物和文字。

背景采用低幅网格与轨道运动，页面和面板带入场过渡。手机布局调整了标题栏、底栏和按钮空间，触摸目标至少 44 像素。弹窗有对话框语义、键盘焦点循环、Escape 关闭和焦点返回。

## 修复的既有弹窗问题

原 CSS 在减少动效时禁用了 transition，但 Framework7 仍等待结束事件，导致弹窗隐藏和监听清理不完成。本次按偏好调用无动画 API；过渡中切换偏好时主动完成已开始的生命周期，并清理成对结束事件回调。该适配针对仓库内固定版本的 Framework7，不改第三方代码。
