# CAD2GIS 0.7.8 — 地图边缘标签留白

延续 0.7.7 的 Windows 窗口布局修复，处理全图状态下几何已完整显示、两端工程编号仍被画布边界截断的问题。EMR 分区的标签文字宽度超过原有固定留白，需要按实际字体及样式的像素范围计算显示空间。

0.7.7 的动态窗口高度、窄屏 CAD/GIS 切换、宽屏双图、人工选点焦点修复，以及 AI 事件与 SVG 加载修复继续保留。文字边界、地图可见区域、源文件完整性分别验证，不以几何范围完整替代文字像素检查。
