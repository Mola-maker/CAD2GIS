# CAD2GIS 0.7.6 — Windows AI 事件、SVG 与安装完整性修复

本版本修复 Windows 工作台中工具输入输出漏记、取消后任务占用、SVG 已下载却未显示，以及大型图纸加载期间状态请求被阻塞的问题。

- AI 工具输入、结果、参数错误和中断均注册事件。每次调用具有独立序号，兼容模型在后续响应中重复使用同一个调用 ID；保留已经完成的写入与继续任务所需记录。
- SVG 报告等待真实文档和图像解码完成后才显示加载成功；刷新会重新请求资源，旧页面的加载失败或旧 AI 结果不会覆盖当前任务。
- 每次资源请求继续执行完整路径核验，并移入线程池。等待期间切换审查结果、注销或会话到期后，旧请求会被拒绝。
- Windows 打包前验证全部文件清单、内容哈希、工具入口，以及 wheel、已安装应用和插件版本的一致性；拒绝遗漏、多余、过期文件和重定向目录。
- 插件协议身份统一为 0.7.6。实际 MCP 注册 59 个工具，桌面另有 7 个工作台工具，共 66 个模型工具。

## 本地验收

- 回归测试 **232 项通过、4 项跳过**；跳过项需要当前 Windows 账户不具备的符号链接创建能力。
- 实际安装到带中文和空格的隔离目录，验证 **14,773 个文件**，完成原生读取、合成转换、应用和启动器检查；卸载后用户数据保留，用户 PATH 恢复。
- 安装版回读 **9 个既有图纸项目、11 个交付范围**，核对 **66 个下载文件**的哈希，成功解码 **1,025 个 PNG 显示实例**并采样渲染 **9 个原生 SVG**；浏览器 JavaScript 错误为零。
- 通过实际注册插件独立重开一个源 SVG QGZ：全部图层有效，**28 个 SVG 绑定、39 个实际标签的字形**核验通过，原交付文件未改变。
- 本地 OpenAI 兼容 HTTP/SSE 协议验收覆盖真实 SDK、MCP 调用、错误恢复、取消和清理；这不代表线上 AI 服务或账号验证完成。

正式 Windows 用户安装已从 0.7.0 升级至 0.7.6，安装文件与冻结 wheel 一致，原用户状态保持不变。已有转换的 `CONDITIONAL`、未匹配和未解析符号状态继续保留；上述检查不构成测量级绝对精度认证，也不自动接受语义候选。线上 AI 服务仍待用户保存配置后验收。
