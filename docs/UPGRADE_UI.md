# CAD2GIS 0.6.0 界面与第一次使用流程

Desktop 的主流程现在是导入图纸、核对源图、选择控制点、预览校正、生成结果。
导入是首页的主要操作，进度和下一步提示紧邻当前图纸。开发资料收进可展开区域；
转换对话、OSM 校正与项目管理保留为主要入口。

GCP 工作区以左右两张地图为中心，控制台、插件说明和高级证据放入工具面板。
选择、校正和残差查看时减少旁支页面干扰，同时保留可打开的审计与诊断入口。
这属于界面层级调整，没有删除诊断数据或绕过原来的导出门禁。

## 控制点与证据

- 已保存点可在地图或列表中选中高亮，按 `0.01 / 0.1 / 1 m` 向东、西、南、北移动，
  支持撤销及恢复最初目标点。真实微调调用服务端 geodesic API，CAD 源点不动。
- 训练 RMSE 与独立检查 RMSE 分别显示；缺少检查点时明确显示未验证。按钮步长不是
  测量精度。旧预览失效或请求未完成时，禁止据此直接生成新结果。
- 可打开 CAD 路线、OSM 路网、两种连接节点和残差线，共五层真实矢量证据。
  图层绑定已应用的匹配 revision，不跟随临时 GCP 预览一起移动。
- 真实 review 初始不加载在线 OSM 瓦片；用户打开开关后才请求当前视野。
  tile image 使用 `strict-origin` Referer；没有修改全局应用策略。
- 拒绝空白经纬度被当成 `0°`，部分动态文本改用安全 DOM 赋值。补充键盘焦点、
  跳至工作区入口、地图焦点和移动布局。

Windows/Linux Desktop 和 Android WebView 复用上述页面代码；共享代码已更新不等于
各操作系统的桌面或手机安装已完成验收。

## GPT Image 装饰图

内置 GPT Image 生成了 1536 × 1024 PNG，用作 Desktop 与 review 的入门装饰。
设计包含浅蓝白底、等距地形块、浮动 CAD 绘图平面、少量钴蓝路径和配准标记，
不含真实地点、文字或测量坐标。

实际资源为 `desktop/assets/onboarding-map-v1.png` 与
`webdemo/assets/onboarding-map-v1.png`。它们是同一装饰素材，带空 alt / 装饰语义；
地图、拓扑和残差继续由真实数据绘制。Webdemo builder 仅将这张新增 PNG 加入白名单。

## 已做与未做的验证

两个 JavaScript 文件通过 `node --check`；Webdemo build、multidemo、reconnect
三个测试文件合计 8 passed，原有 WebSocket 测试未弱化。真实 GCP 的距离、撤销、
revision 冲突及证据 API 由后端测试覆盖，最终全库结果见发布报告。

**本轮没有完成浏览器交互或视觉验收，也没有成功生成界面截图。**
首次本地 HTTP 导航挂起；后续共享文件 URL 被浏览器策略拒绝，已停止尝试。
代码检查和后端测试不能证明所有分辨率、真实瓦片网络行为或触屏交互都已正确。

Webdemo 包含既有十份 DWG 的派生演示数据，不含 DWG/GPKG 原文件；演示画面不代表
本轮九份图纸的最终转换结果。静态演示仅记录选点，不执行真实校正。
