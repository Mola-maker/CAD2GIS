# WebDemo typography system

The public CAD2GIS interface self-hosts small WOFF2 subsets so headings,
Chinese body copy, technical labels, and command output render consistently
without a runtime font CDN dependency.

| Role | Family | Use |
| --- | --- | --- |
| Display | Smiley Sans Oblique | Chinese hero and section headings only |
| Body | Noto Sans SC Variable | Paragraphs, forms, controls, and map labels |
| Interface | Space Grotesk Variable | Latin navigation, badges, metrics, and compact UI labels |
| Code | IBM Plex Mono | Commands, hashes, coordinates, and terminal output |
| Brand | CAD2GIS Hero Display | Repo-native geometric Latin capitals in the hero |

Smiley Sans is intentionally limited to large display text; its own project
recommends it for titles rather than UI body copy. Noto Sans SC carries the
full Chinese reading surface, Space Grotesk gives the compact Latin interface
a consistent rhythm, and IBM Plex Mono preserves technical alignment.

Upstream sources:

- Smiley Sans: https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1
- Noto Sans SC: https://fonts.google.com/specimen/Noto+Sans+SC
- Space Grotesk: https://fonts.google.com/specimen/Space+Grotesk
- IBM Plex Mono: https://fonts.google.com/specimen/IBM+Plex+Mono

All four upstream families are distributed under the SIL Open Font License
1.1. Their license texts ship beside the subsets in
`src/cad2gis/webdemo/assets/font-licenses/`. The generated subsets contain only
glyphs used by the WebDemo and remain under their upstream family names; the
repo-native CAD2GIS Hero Display is generated by `tools/build_hero_font.py`.
