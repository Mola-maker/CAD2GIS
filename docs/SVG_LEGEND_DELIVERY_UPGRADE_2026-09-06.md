# 图例 SVG 可选转换与九图交付升级

## 本轮目标和验收门槛

用户要求：转换时显式可选的图例 SVG，图例和图上对象一一对应且不遗漏；在已核验九图几何基线上增加 SVG；
最终 QGZ、HTML 及插件跨路径、跨进程、跨环境可用。长度优先 CAD 标注且不带 CAD 后缀，只有无标注计算值带来源标签。

## 已确认的原交付缺陷

`EMR29619-with-SVG.qgz` 中 GPKG 虽被压缩入包，QGS 数据源仍写了生成进程的绝对临时路径；
`ProjectViewSettings/DefaultViewExtent` 全为 0 且 CRS 为空。同进程复制测试误用了仍存在的原临时文件；
独立渲染时重新指定范围掩盖了默认打开白屏。必须用全新进程读取下载副本，检查真正序列化的默认视图和路径。

## 分层入口

1. 现有九图基线保持不可变，逐图冻结 source SHA、GPKG 几何/字段及原转换配置。新增 SVG 是展示层变更，
   不重新猜测分类或移动坐标。Manado 原图 79BE 修复使用已独立审计的新基线，单独列明差异。
2. 源图例候选发现：联合图纸边缘区域、LEGEND/KETERANGAN 等标题、对齐图例布局及块定义。
   “靠近边缘”只作为线索；图例可以在纸空间或任何边，不以坐标侧别直接确认。保留图例原文和实体 handle。
3. 精确对应：图例样本与地图实例通过源块结构、可见性状态、内部文字、颜色、几何签名关联。
   保存 source SHA、legend entity、map entity、symbol ID、SVG SHA 及匹配依据；歧义、不支持对象和缺失必须列出，
   不允许用一个示例或同色圆圈冒充全图匹配。
4. 独立 SQLite 资产库继续独立。转换入口提供 off/candidate/reviewed 模式；off 为默认，candidate 输出审查资产，
   reviewed 仅应用来源契约通过的匹配。候选生成与交付使用分开记录，可由 AI 查询和审查。
5. 最终打包保留完整可编辑 ZIP（QGZ、GPKG、SVG/QML、CSV、HTML、manifest、checksums），
   另提供经跨进程验证的单文件查看版本；两者入口标识明确。绝不让网页下载一个依赖未随附文件的裸 QGZ。
6. HTML 提供九图索引、基线来源、图例/实例配对、完整性数字、异常列表、长度规则、打开方法与验证记录。

## 检验顺序

- 先修复单图：序列化路径不含机器临时目录；非空默认视图及有效 CRS；全新 QGIS 进程打开下载副本，
  不手动重设范围来掩盖失败。对默认画布和局部符号实际渲染并记录。
- 图例入口：真实边缘图例与实例对照，覆盖完整，不支持或歧义维持可见，审查未通过不宣称完整。
- 九图逐个重包装：基线几何/字段差异核验、数据库完整性、资源闭包、每个图层和 SVG 读取、
  默认视图非空、单文件隔离打开、ZIP 搬移打开、HTTP 下载哈希。任一失败阻止最终交付通过。
- Linux 无 AutoCAD 的可选流程验证；WSL 内核崩溃必须如实记录，不能将 Windows 结果算作 Linux 通过。

此文是执行设计与验收要求，不是完成报告。逐项结果追加到 validation 及 VALIDATION_ISSUES_2026-09-06.md。
