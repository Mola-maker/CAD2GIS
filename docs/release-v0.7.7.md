# CAD2GIS 0.7.7 — Windows 地图可视区域修复

修复 Windows 地图页只显示局部、GIS 下半部被裁切，以及展开工作区后仍无法完整查看的问题。旧版外层 iframe 与内层地图分别使用固定高度，叠加标题、分区和底部导航后超出实际窗口；地图数据已经加载完整，单独点击“显示全部”无法消除外部遮挡。

- 地图使用窗口剩余高度，并按底部导航的实际位置预留空间。
- 宽屏保留 CAD/GIS 双图；窄屏通过“CAD 源图 / GIS 地图”切换完整地图，图层与人工校正面板可收起。
- 全图状态随窗口变化重新适配。用户拖动或缩放后保留当前中心和比例，点击“显示全部”恢复全图。
- 从 GIS 视图开始人工选点时，自动切回 CAD、收起面板并聚焦地图；键盘关闭面板后返回入口。

本次没有修改转换几何、CRS、图层数量或已有交付文件，继续保留已有的条件通过、未匹配和未解析符号状态。

## 验证方法

新增 `tests/browser/desktop_map_layout.cjs` 使用真实应用资源和 OpenLayers，以及明确标记的合成 API 几何，检查 711×898、720×900、1280×800、1920×1080 的地图可见数量、边界、画布尺寸和完整范围，并覆盖展开、隐藏初始化、拖动缩放保留及人工选点。

在安装了 Playwright 和 Edge 的环境中执行：

```sh
node tests/browser/desktop_map_layout.cjs tmp/desktop-map-layout
```

同时对已有 Lamteh MAIN 和 Manado 交付执行实际浏览器复核。源应用回归与安装包回归分别记录；浏览器显示完整不构成测量级绝对精度认证。外部 AI 服务验收仍须使用用户保存的服务配置。
