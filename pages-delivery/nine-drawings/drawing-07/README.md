# CAD2GIS QGIS delivery

Unzip the entire package; open delivery.qgz. Keep delivery.gpkg and styles beside it.

GeoPackage is SQLite. CSV files contain every non-geometry attribute. CABLE labels display selected length in metres and its source; grid/geodesic/CAD measurements remain distinct. Empty labels are not invented.

CONDITIONAL: no independent surveyed GCP acceptance. A QGIS project and visual overlay do not certify absolute accuracy. Partitions are separate projects and may share assets with the main project.

Original GeoPackage bytes are preserved. QML label settings are presentation overrides. This portable delivery excludes raw DWG and full source/evidence databases; AI source-bound edits require the original reviewed run and project.
